## Что это

**AnchorJS** — JavaScript-библиотека студии: якоря и навигация по контенту, DX для документации и UI, небольшой предсказуемый API для веб-инструментов Stancore.

Платформенное ядро рядом — **[Monolith](https://github.com/StancoreStudio/Monolith)**. Каталог разработок: **[developments](https://github.com/StancoreStudio/developments)**.

## Зачем

- Подключаемый клиентский слой без тяжёлого фреймворка «на каждый чих».
- Единый стиль якорей, оглавлений и переходов в docs/UI.
- Стыковка с сервисами на Monolith (справка, админки, публичные страницы).
- API, который можно объяснить за одну страницу README.

## Статус

Репозиторий открыт как публичная точка входа разработки. Публичный API будет фиксироваться в этом README по мере стабилизации.
